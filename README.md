# iFly EMU releases

Public builds of [iFly EMU](https://ifly-emu.com), the Dreamcast, Naomi and Atomiswave emulator for iPhone, iPad and Apple TV. The app's source lives in a private repository; this one only hosts the build files, so the website and sideload sources can link to them.

- **Sideload (AltStore / SideStore):** add the source `https://provenance-emu.com/apps.json`, or download the `.ipa` from [Releases](https://github.com/JoeMatt/iFly-releases/releases).
- **TestFlight and the App Store:** see [ifly-emu.com](https://ifly-emu.com).

Each release is a beta build. Its notes list what changed since the previous one.
